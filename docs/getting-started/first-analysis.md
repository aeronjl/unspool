# First analysis: forecast a later session

This ten-minute example answers one bounded question: **does stimulus sensitivity improve
prediction of each animal's next session relative to a stationary choice bias?** It uses a
small simulated dataset so the complete analysis runs without downloading data.

The example deliberately follows the same order expected for a real study:

1. preserve animal, session, trial, and chronology in a [`Study`](../data-contract.md);
2. declare what the observed columns mean with a [`TaskSpec`](../task-contract.md);
3. protect the final session before fitting either candidate;
4. score both candidates on identical animals and trials; and
5. keep the unit-balanced uncertainty and fit audits next to the headline result.

## Read the result

The `Study` contains 1,200 trials from six animals, with five explicitly ordered sessions
per animal. The `TaskSpec` verifies all choices and predictors without changing a row. The
split then exposes sessions 1–4 to fitting and keeps session 5 untouched for scoring.

The `stimulus` candidate has the lower animal-balanced held-out log loss. Every animal has
a positive paired improvement in this particular simulation, and both fits pass the
normalized audit. That supports the narrow predictive statement above. It does **not**
show that a psychometric model is a sufficient cognitive explanation, that parameters are
recoverable, or that the same ranking will hold in another design.

## Adapt it to your table

Replace `make_example_study()` with a dataframe mapping:

```python
study = Study.from_dataframe(
    trials,
    subject="mouse",
    session="session_id",
    trial="trial_index",
    session_order="training_day",
)
```

Then make four decisions explicit before changing the model:

| Decision | Question to answer |
| --- | --- |
| Task | Which values are choices, omissions, predictors, rewards, and response times? |
| Clock | Does `session_order` represent the scientific time coordinate you intend? |
| Boundary | Are you forecasting later sessions, new animals, a new laboratory, or some combination? |
| Unit | Should animals, sessions, laboratories, or trials receive equal inferential weight? |

For a candidate set chosen using data, move selection inside the training fold with
[`nested_select_model`](../comparison.md). Before interpreting parameters or a winning
family, add [parameter and model recovery](../model-recovery.md) under the actual design.
